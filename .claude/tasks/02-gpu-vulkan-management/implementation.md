# Implementation Summary: Gestion GPU Vulkan Robuste

## Status: COMPLETED

Date: 2025-01-09

---

## Changes Made

### 1. `src-tauri/src/config.rs`

**Added:**
- `gpu_device_index: Option<u32>` field with `#[serde(default)]` for backward compatibility
- Prepared for future multi-GPU device selection

### 2. `src-tauri/src/stt_whisper.rs`

**Major refactoring:**

- Added GPU failure counter with atomic operations:
  - `static GPU_FAILURE_COUNT: AtomicU32`
  - `const MAX_GPU_FAILURES: u32 = 3`

- Added public functions:
  - `record_gpu_failure() -> u32` - Increments and returns new count
  - `reset_gpu_failures()` - Resets counter after user action
  - `get_gpu_failure_count() -> u32` - Reads current count
  - `is_gpu_disabled_by_failures() -> bool` - True if >= 3 failures

- Created `GpuInitResult` struct:
  - `mode: String` ("gpu" or "cpu")
  - `device_name: Option<String>`
  - `fallback_reason: Option<String>`
  - `failure_count: u32`

- Modified `WhisperSttEngine`:
  - Added `gpu_device_index: Option<u32>` field
  - Updated `new()` to accept 4 parameters
  - Rewrote `initialize()` to return `Result<GpuInitResult, WhisperError>`
  - GPU is auto-disabled after 3 consecutive failures
  - Failure counter resets on GPU success

### 3. `src-tauri/src/lib.rs`

**Updated:**

- Extended `GpuInfo` struct:
  - Added `failure_count: u32`
  - Added `disabled_by_failures: bool`

- Added `GpuStatus` struct for real-time monitoring

- Added new Tauri commands:
  - `get_gpu_status()` - Returns current GPU status
  - `reset_gpu_failure_count()` - Allows user to retry GPU

- Updated `get_gpu_info()` to include failure information

- Fixed `SttEngine::new()` to pass `gpu_device_index`

### 4. `src/bindings.ts`

**Auto-generated by tauri-specta:**
- New types: `GpuStatus`, updated `GpuInfo`, updated `AppConfig`
- New commands: `getGpuStatus()`, `resetGpuFailureCount()`

### 5. `src/stores/settingsStore.ts`

**Added:**
- `gpuStatus: GpuStatus | null` state
- `gpuDeviceIndex: number | null` state
- `setGpuStatus()` and `setGpuDeviceIndex()` actions
- `gpuDeviceIndex` in persistence partialize

### 6. `src/components/SettingsWindow.tsx`

**Enhanced GPU section UI:**

- Current mode status badge (GPU Active / CPU Mode)
- GPU failure warning panel:
  - Shows failure count
  - Shows if GPU is auto-disabled
  - "Retry GPU" button to reset counter
- Toggle disabled when GPU is auto-disabled by failures
- Color-coded badges (green for GPU, yellow for CPU fallback)

## Architecture

```
┌─────────────────────┐
│  SettingsWindow.tsx │ ← UI displays GPU status, failure warnings
├─────────────────────┤
│   settingsStore.ts  │ ← Stores gpuInfo, gpuStatus
├─────────────────────┤
│     bindings.ts     │ ← Auto-generated types & commands
├─────────────────────┤
│       lib.rs        │ ← Tauri commands: get_gpu_info, get_gpu_status, reset_gpu_failure_count
├─────────────────────┤
│   stt_whisper.rs    │ ← WhisperSttEngine with GPU failure tracking
├─────────────────────┤
│     config.rs       │ ← AppConfig with gpu_device_index
└─────────────────────┘
```

---

## Backward Compatibility

- All new config fields use `#[serde(default)]` for backward compatibility
- Old configs without `gpu_device_index` will deserialize with `None`
- No breaking changes for users

---

## Known Limitations

1. **Multi-GPU Selection**: `gpu_device_index` is prepared but UI selector not yet implemented
2. **VRAM Monitoring**: Not implemented (whisper-rs doesn't expose VRAM usage)
3. **Real-time GPU Status**: Status is loaded on Settings open, not continuously updated
