# Code of Conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat people as you would want to be treated. Technical disagreement
is welcome and useful; contempt is not. Criticise the code, not the person who
wrote it.

Unacceptable behaviour can be reported privately through GitHub's
**Report content** feature, or by opening a private security advisory on this
repository if you would rather it stay out of sight. Reports are handled by the
maintainer, who will keep the reporter's identity confidential.
